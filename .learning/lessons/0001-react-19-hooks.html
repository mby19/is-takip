Ders 1: React 19 Yeni Hook'ları

İş Takip projende kullanabileceğin yeni hook'lar

React 19 ile gelen yeni hook'lar, form yönetimi ve async state'i çok daha temiz hale getiriyor. Bu derste üç önemli hook'u öğreneceksin: useActionState, useOptimistic, ve use().

1. useActionState — Form State Yönetimi

Eskiden form submit'leri için useState + useTransition karışımı kullanıyorduk. useActionState her şeyi tek bir hook'ta topluyor.

Ne zaman kullanılır? Form submit, loading state, error handling — hepsi bir arada. 
// Eski yöntem (React 18)
const [isPending, setIsPending] = useState(false);
const [error, setError] = useState(null);

const handleSubmit = async (e) => {
  e.preventDefault();
  setIsPending(true);
  try {
    await createWorker(formData);
  } catch (err) {
    setError(err);
  } finally {
    setIsPending(false);
  }
};

// Yeni yöntem (React 19)
const [state, formAction, isPending] = useActionState(
  async (previousState, formData) => {
    const result = await createWorker(formData);
    return result;
  },
  null // initial state
);

2. useOptimistic — Anında Geri Bildirim

Kullanıcı bir şey yaptığında, sonucu beklemeden hemen看到显示。Sonra sunucu yanıtı gelince gerçek değerle değiştir.

İş Takip'te kullanım alanı: Çalışan eklerken, sunucu yanıtını beklemeden listede hemen göster. 
const [workers, addOptimistic] = useOptimistic(
  currentWorkers,
  (state, newWorker) => [...state, { ...newWorker, pending: true }]
);

const handleAddWorker = async (workerData) => {
  // 1. Anında göster (optimistic)
  addOptimistic(workerData);
  
  // 2. Sunucuya gönder
  await createWorker(workerData);
  
  // 3. Gerçek veriyle değiştir (revalidate)
  revalidateWorkers();
};

Bu sayede kullanıcı "Ekle" butonuna bastığında anında看到新员工出现在列表中，而不是等待网络请求。

3. use() — Promise ve Context Okuma

Yeni use() hook'u, component render sırasında Promise okuyabilir. Bu, useEffect + useState kombinasyonunu basitleştirir.

// Eski yöntem
const [data, setData] = useState(null);
const [loading, setLoading] = useState(true);

useEffect(() => {
  fetchData().then(setData).finally(() => setLoading(false));
}, []);

// Yeni yöntem (React 19)
const data = use(fetchData());
⚠️ Dikkat: use() sadece Client Component'lerde çalışır. Server Component'lerde zaten async/await kullanabilirsin.

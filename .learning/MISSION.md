# Öğrenme Misyonu

## Neden Bu Teknolojileri Öğreniyorum?

İş Takip uygulamasını geliştirmek için React 19, TypeScript ve Zustand'ı daha derinlemesine öğrenmek istiyorum.

## Hedef

Bu üç teknolojiyi proje context'inde ustalaşarak:

- Daha temiz ve bakımı kolon kod yazmak
- State management'i doğru yapmak
- Type safety ile bug'ları compile time'da yakalamak

## Mevcut Seviye

- Temel React bilgisi var (component'ler, hooks)
- TypeScript kullanıyorum ama advanced patterns eksik
- Zustand basit store'lar için kullanıyorum

## Öğrenme Önceliği

1. **React 19** — Component patterns, hooks, performance
2. **TypeScript** — Advanced types, generics, utility types
3. **Zustand** — Store patterns, middlewares, persistence

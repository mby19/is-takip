React 19 Hook'ları Hızlı Referans

useActionState

Form state yönetimi için. useState + useTransition yerine.

const [state, formAction, isPending] = useActionState(
  async (prevState, formData) => {
    // prevState: önceki state
    // FormData instance
    return newState;
  },
  initialState
);
ParametreTürAçıklama
actionasync functionForm submit handler
initialStateanyBaşlangıç state'i
return [0]anyMevcut state
return [1]functionform action (form'a verilir)
return [2]booleanLoading durumu
İpucu: formAction'ı <form action={formAction}> olarak kullan. onSubmit değil!

useOptimistic

Optimistic update için. Sunucu yanıtı beklemeden anında UI güncelle.

const [optimistic, addOptimistic] = useOptimistic(
  currentState,
  (state, newValue) => mergedState
);
ParametreTürAçıklama
stateanyMevcut state (genelde veri)
updateFnfunctionOptimistic state nasıl birleştirilir
return [0]anyOptimistic state (gösterilen)
return [1]functionOptimistic update tetikler
İpucu: addOptimistic sadece geçici. Gerçek veri geldiğinde otomatik değişir.

use()

Render sırasında Promise veya Context oku.

// Promise okuma
const data = use(fetchData());

// Context okuma (useContext yerine)
const theme = use(ThemeContext);
KullanımDurumNot
use(promise)✅ ÇalışıyorSuspense ile birlikte kullan
use(context)✅ ÇalışıyoruseContext yerine
Conditional use()❌ Yasakif içinde kullanma
Loop içinde use()❌ Yasakfor/while içinde kullanma
Uyarı: use() sadece component render sırasında çalışır. Event handler veya effect içinde kullanma.
